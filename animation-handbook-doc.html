01

它到底是什么

一句话：176 种不依赖任何三方库的纯原生 Web 动效活字典与 AI 提示词库。

  • 定位：Animation Handbook 是由 Matin Monshizadeh 发起的开源 Web 动效手册，仓库 matinmonshizadeh/animation-handbook，采用 MIT 开源协议。
  • 解决的痛点：前端开发者和设计师在做网页时，常苦于「看到好动效却不知道名字」、「引入重型 GSAP 或三方库让页面体积暴增」、「不知道如何精准向 AI 描述微交互细节」。Handbook 把这些难题一次性解决。
  • 核心三步法： ① 选动效（按部件分类或通过 3 个问题的交互式 Finder 定位）； ② 看运行（实时调节速度、方向等参数，查看内部图层原理）； ③ 复制 Prompt（直接把带参数的自然语言描述贴给 AI 助手生成代码）。
  • 零依赖原则：所有 176 种动效均由干净的 HTML、CSS 和原生 JavaScript 构成，不依赖 CDN、不需要 Webpack/Vite 编译打包，双击 index.html 即可在本地无缝离线运行。
纯粹的启发与教学：项目的核心目的在于“启发与传授”，而不是推销任何商业 UI 库；所有代码完全开放、直截了当。
02

7 大分类与全景技法

分类严整，涵盖从页面入场到微交互的全生命周期。

  • 01 滚动驱动（Scroll-Based · 27 种）：视差滚动、卡片堆叠（Stacking Cards）、进度条（Progress Bar）、时间轴墨线绘制（SVG Line Draw）、文字随滚动渐进点亮（Text Fill）。
  • 02 入场与离场（Entrance & Exit · 15 种）：错峰级联显现（Stagger Reveal）、遮罩剪切擦除（Clip-path）、3D 翻转入场、优雅淡入。
  • 03 页面切换（Page Transitions · 17 种）：原生 View Transitions API 驱动的平滑变形、折叠卷轴、百叶窗、光圈扩散。
  • 04 微交互（Micro-Interactions · 44 种）：磁吸按钮（Magnetic Button）、打勾绘制（Checkmark Draw）、光斑跟随（Spotlight Hover）、主题太阳/月亮切换（Theme Toggle Morph）、按压形变。
  • 05 文字与排印（Text & Typography · 19 种）：流光渐变（Gradient Animation）、打字机效果、乱码解码渐显（Scramble Text）、高亮划线（Highlighter Sweep）。
  • 06 3D 与进阶特效（3D & Advanced · 28 种）：视差 3D 微倾斜（Parallax 3D Tilt）、流体模拟、玻璃拟态光泽（Glassmorphism）、Canvas 粒子网络。
  • 07 环境氛围背景（Ambient & Background · 26 种）：极光流光（Aurora Gradient）、呼吸柔光（Breathing Glow）、点阵视差、胶片噪点微粒。
分类精细：无论你是要改一个按钮的悬浮反馈，还是要构建一整套故事叙事流落地页，都能在对应分类中快速找到灵感。

零依赖接入与离线运行

克隆即跑，没有任何 node_modules 困扰。

  • 极简架构：仓库内每一个动效都有独立的子目录，里面只包含一个自洽的 index.html 和一份详解 README.md。
  • 离线运行支持：无需配置 Node、npm 或构建工具；只需通过 Python 自带的 http.server 或 VSCode Live Server 即可随时启动本地交互预览。
  • 零损耗移植：想要哪一个动效，直接打开对应目录的 index.html，复制当中的几十行 CSS 和 JS 片段即可粘贴到你的 Vue、React、Svelte 或原生 HTML 项目中。

06

设计哲学与性能优化

现代 Web 动效准则：只用合成器属性，绝不阻塞主线程。

  • 只操作合成层属性：动画严格局限在 transform 和 opacity 上，杜绝频繁触发 DOM 重排（Reflow）的 top、left、width、height 动画，确保手机与低功耗设备稳定 60/120fps。
  • GPU 硬件加速与 will-change：对高频交互卡片合理声明 will-change: transform，提前将其提升到独立图层，移出时及时清理避免显存泄漏。
  • 原生 CSS 滚动时间轴：在支持的环境中优先使用 animation-timeline: scroll()，完全跳过 JS 引擎的逐帧计算，交由浏览器内核异步丝滑渲染。
  • 无障碍优先（A11y）：全面遵循 @media (prefers-reduced-motion: reduce) 规范，对开启系统减弱动画偏好的用户自动降级为平置静态或瞬时切换。

07

原理透视与对比机制

看清动效本质：不仅看效果，更把背后的数学与图层可视化。

  • See Inside（内部透视）：点击每个演示上方的「See Inside」按钮，舞台会立刻高亮显示辅助参考线、隐藏遮罩层以及实时计算的坐标数值（如光标相对卡片的百分比与旋转角）。
  • 俯瞰视角剖析：在 3D 倾斜演示中，提供“从上方俯视（Seen from above）”的线框模型，直观展示视距 perspective 与观察者眼睛位置的关系。
  • Compare（左右对照）：并排显示「无动效基准版」与「带动效升级版」，直观呈现一个微小的光斑或 2 像素的位移如何从根本上拉开质感差距。
  • Production Gotchas（避坑备忘）：每个技术目录的 README 均明确指出实际工程中可能踩坑的浏览器兼容性、层级上下文遮挡与性能陷阱。
知其然亦知其所以然：通过透视模式看懂数学变换和坐标计算后，你就能随心所欲组合出属于自己网站的专属交互语言。
08

选型建议与工程落地

克制而不喧宾夺主，让动效为内容服务，而不是为了动而动。

  • 首选轻量点睛动效：优先落地 3D 微倾斜、光斑漫反射、顶部阅读进度条、代码复制打勾反馈等耗时极短（<0.3s）且直接改善触觉感知的微交互。
  • 谨慎使用重型粒子与 3D 着色器：Canvas 粒子流、流体模拟等重度特效仅建议在特殊节日、大型营销 Hero 区少量使用，避免长时间占用用户 CPU/GPU。
  • 与业务调性严格统一：工具类网站注重利落干脆（100-200ms），故事类叙事页面注重沉浸从容（300-500ms），全站动效应统一缓动曲线（如 cubic-bezier(.16, 1, .3, 1)）。
  • 本站成功实践：本网站首页个人名片的 3D 微倾斜跟随、四格技能卡微箭头滑出、长文顶部渐变进度条，正是取材于 Animation Handbook 的精髓，实现 0 额外依赖并达成 100% 自动化测试通过。
总结：动效的最高境界是“润物细无声”——用户感觉不到突兀的炫技，但用起来就是觉得顺滑、精致、有质感。
