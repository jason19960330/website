Answer me with HTML 完整指南

一款给 AI 智能体装的 Agent Skill：遇到复杂问题，Agent 不再甩给你一堵文字墙， 而是写一份极短的 Markdown 稿件，由它自带的 CLI 在本地生成一页能看懂的单页 HTML。 模型要写的 token 只有直接手写 HTML 的约 1/8。指南整理自其公开仓库。

01

它到底是什么

一个让 AI 用「一页 HTML」而不是「一堵文字」回答你的 Agent Skill。

  • 定位是「Agent 的输出方式升级」：装好后，你像平时一样提问（「讲讲 TCP 三次握手」「Redis 和 Memcached 怎么选」），Agent 不再只回一堆文字，而是顺手生成一页带图表、表格、代码的单页 HTML，约 50 毫秒就能打开。
  • 模型只写内容，不写样式：它只产出一份极短的 Markdown 稿件，排版、配色、暗色模式、流程图坐标全部交给 skill 自带的 CLI（am）在本地算好——模型不用再手写几百行每次都差不多的 CSS 和 SVG。
  • 兼容 70+ 种 Agent：Claude Code、Codex、Cursor、OpenCode、Pi、DeepSeek Harness 都能装；任何能运行 shell 命令的智能体都能用。作者 @QingYunA 以 MIT 开源。
  • 产物是单文件 HTML：不引用任何 CDN 或外部字体，断网也能打开，发给别人也能看，也能内嵌生成它的 Markdown 原稿随时找回。
形态：一个 Agent Skill（不是网站、不是 App），核心是 SKILL.md 触发说明 + 一个打包好的无依赖 CLI am.mjs（仅需 Node.js 20+）。它扩展的是你现有编码/对话智能体的「回答方式」。
02

核心能力一览

把「画网页」的活从模型手里拿走后，又快又省，还顺手多了一堆能力。

  • token 省约 8 倍：直接手写 HTML 平均约 4,893 token，用这个 skill 模型只写约 612 token 的 Markdown 稿件——约为手写 HTML 的 1/8。
  • 耗时快约 2.6 倍：同样的问题（Claude Sonnet 5.5），直接要 HTML 约 31 秒，用本 skill 约 12 秒。
  • 解释视频省得更多：一次小测试里，输出 token 少约 18 倍、快约 12 倍——图随旁白一步步画出来，配音内嵌离线可播。
  • 版面由代码计算：面板位置、流程图/时序图坐标都是算出来的，不靠模型猜，文字不会被截断、网格不留空洞；写错时 CLI 给出行号、组件名和正确示例，Agent 改一次即可。
  • 三套主题 + 多语言：blueprint（图纸风）、shadcn（卡片风）、paper（长文）均带亮/暗色，可页面内随时切换；简中/繁中/英文/日文按钮与字体齐全；默认按内容自动选主题。
小提示：花费并没有 token 降得那么多（约便宜 15%），因为每一轮都要读系统提示、你的问题和对话记录——用不用 skill 都一样。真正省的是「等待时间」和「模型写废话的概率」。

04

稿件怎么写

你（或 Agent）只需写一份「扩展 Markdown 稿件」，剩下的交给 CLI。

  • Frontmatter 定标题：稿件顶部用 --- 写 title:，CLI 据此选模板、排面板、套主题。
  • 普通 Markdown 写正文：标题、列表、表格、代码块、引用都能用；表格单元格写 ok / no / warn 会自动变成 ✓ ✗ !，表格后加 {table sort filter} 开启交互排序筛选。
  • 围栏代码块即图表：用 ```flow / ```sequence / ```tree / ```timeline / ```er / ```chart 等语言标记，CLI 自动布局；例如 ```sequence 画时序图、```flow 画架构/调用链。
  • 真实代码不靠手抄：代码块可写 src=路径 lines=起-止 直接引用你文件里的几行真实代码；当前目录以外的文件和存放密钥的文件会被拒绝。
  • 面板分栏：标题后加 {span=2} 之类控制跨栏；ask 组件可在页面上放「需要你做的决定」，选项默认都不选中，你选完合成文字贴回 Agent。
要不要出页面由 Agent 判断：概念关系复杂、有多步流程、要做多维对比时才出页面；一句话能说清的问题（如「ls 怎么看隐藏文件」）照常用文字回答，不出页面。你也可以直接说「用 HTML 讲一下……」强制出页。
05

组件一览

Agent 会按「信息的形状」自动挑组件，你基本不用指定。

  • flow：架构、调用链、决策分支；自动布局，支持分组、判断框、数据库。
  • sequence：几方之间按时间顺序来回发消息（如 TCP 握手）。
  • er：数据模型——实体带字段（PK/FK/UK）和鸦爪式关系连线。
  • tree：目录、模块、分类体系；timeline：历史、版本、阶段；limits：当前值 vs 上限对比。
  • chart：用数字表格画柱状/折线/饼图，支持多系列、负值、高亮一行；annot 逐词点评；kv 元信息；callout 结论/提示/警告。
  • 表格与代码块：多维对比用表格（✓✗! 标记），代码块可引用真实文件（src= lines=）或手写示意代码。
命令速查：每个组件的完整写法都用 am help <组件名> 查看；不经由 Agent、直接在命令行也能渲染——am render 稿件.md 即可出页。
06

主题、写作检查与离线

好看、可读、可控，而且产物完全自包含。

  • 三套主题随意切：blueprint（图纸风）、shadcn（卡片风）、paper（长文），均带亮/暗色；页面右上角下拉框随时切换，也能加自己的主题或从主题库取一个。
  • ASD-STE100 受控写作检查：按飞机维修手册那套受控英语的思路查稿件——句长、用词绕不绕、被动语态，以及中文错别字和含糊词都会提醒（默认只提醒不拦）；style: strict 可让不达标稿件不生成。
  • 单文件、零依赖：产物是一个 .html，不引用任何 CDN 或外部字体，断网能开、转发能看；页面内可切主题、汇总回复、复制生成这一页的 Markdown 原稿。
  • 配置走斜杠命令：open（自动开浏览器）、theme、mode（亮/暗）、style（写作检查）、scale（字号，图表跟着变）、voice（视频配音）等；Claude Code 用 /answer-me-with-html:config，其他 Agent 用 /answer-me-with-html config 或终端 am config。

07

解释视频与页面互动

不止静态页：还能出 3Blue1Brown 风格的解释视频，页面本身也能来回互动。

  • 解释视频：直接说「给 TCP 握手做个 3b1b 风格的视频」，Agent 写的稿件只多一层旁白（每行一拍）。am video 把它做成播放页：图随旁白一步步画、镜头跟方括号里的节点走，配音内嵌离线可播。
  • 本地导出：播放器带章节栏、倍速按钮和导出按钮；同一视频由浏览器自己编码并下载（本地文件或 localhost 打开即可，不需要 ffmpeg）；加 --mp4 另存 MP4（需 ffmpeg），加 --webm 存页面自编码的 WebM（不需 ffmpeg）。
  • 在页面上回复：可对任一面板写评论，或在 ask 决定里选选项；点「回复」按钮，你的选择和评论会合成一段文字，贴回给 Agent 即可。
  • 能找回原稿：每页都内嵌了生成它的 Markdown，点「复制源稿」就能拿回来改，再丢给 am render 重出。
只有你要视频时 Agent 才做视频：解释视频是按需触发的，不会在你没要求时偷偷生成。高频模式下自动出的小页面也只生成、不弹浏览器，不打断你。
08

适用场景与边界

什么时候该装、什么时候有门槛，以及它的设计取舍。

  • 适合：需要「看懂」的讲解：原理、架构、调用链、状态机、生命周期、历史演进；对比、权衡、带利弊的决策；诊断、评审、调查（尤其是多因多果要排序时）。
  • 适合：给团队/读者一页成稿：把一篇长回答凝成一页可分享、可离线、可转发的 HTML，比甩一段聊天记录友好得多。
  • 前提门槛低：只要本机有 Node.js 20+，装好即用；CLI 自带、无需 npm install；不填任何 key、不联网也能渲染（联网仅用于每天查一次更新）。
  • 边界：它产出「单页 HTML 讲解」，不是可交互 Web 应用，也不是数据库/后端；组件由 CLI 计算布局，深度定制主题需要你改主题文件或写原始 html/svg 块。
  • 与本站 Visualizer 互补：本站内置的图表是「聊天内联的小图」，它生成的是「完整、可保存、可分享的独立 HTML 页」——要内联示意用前者，要一页成稿用后者。
