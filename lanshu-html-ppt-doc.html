01

它到底是什么

一句话：交付物是一个 HTML 文件，不是一份 .pptx。

  • 定位：由岚叔 / Lanshu 整理维护，仓库 cclank/lanshu-html-ppt-templates，在线目录 ppt.lanshuagent.com。原生 HTML / CSS / JavaScript、字体内嵌，模板播放不需要安装依赖、账号、后端或 API 密钥，下载到本地可离线放映。
  • 两条用法：① 打开在线模板目录选风格 → 点封面放映或「下载 HTML」→ 用编辑器或 AI 助手改写正文与演讲备注；② 把整套资源安装为 Skill，让 AI 助手完成选型、内容改写和演示制作。
  • Skill 与工具一起交付：SKILL.md 是技能入口，选型目录、创作规则、模板复制、静态校验和安全安装器都在完整包里。Skill 会按内容挑模板、复制完整资源、改写页面与备注、跑静态检查，并在可用浏览器里验证实际呈现。
  • 表达更丰富：SVG 图表、Canvas 数据变形、生成艺术、空间视差、镜头飞行与可调业务模型，全都写在同一个文件里，不靠外部服务。
体量：仓库 2026-11-04 创建、最近提交 11-12，约 64 star / 11 fork / 0 open issue，主体语言 HTML，仓库约 44 MB（内嵌字体与缩略图占大头）。项目还很新，长期维护节奏仍需观察。
02

30 套模板 / 338 页

按场景挑，别只按好看挑。

  • 两组各 15 套：经典 / 叙事一侧覆盖瑞士国际主义、杂志编辑、暗夜极光、黑金奢华、咨询战略、新中式等；交互 / 实验一侧覆盖数据变形、生成艺术、电影片头、活体模型、终端、地球仪、地铁线路、漫画分镜等。
  • 21–30 是本次新增 10 套：学术答辩、便当格、黑板课堂、对话叙事、像素闯关、报纸头版、蓝图工程、政企汇报、地铁线路、漫画分镜；模板库因此从 20 套扩到 30 套、338 页，首页还加了「新增 10 套」筛选与卡片悬停动态预览。
  • 每套 10–12 页，包含正文结构与逐页演讲备注。目录里每套都写了「适合场景」，例如 07-consulting → 战略汇报 / 董事会材料，28-official → 年度工作汇报 / 国企述职，29-metro → 产品路线图 / 里程碑。
  • 打印样式分两类：23 套源码内已有多页打印适配，可用浏览器打印到 PDF（勾「背景图形」、边距选「无」）；其余偏浏览器放映，交互、动画和临时状态只能在浏览器里看，PDF 效果需实测。
  • 机器可读的选型依据：references/template-catalog.md 是能力分类，catalog.json 存 30 套元数据与原始文件 SHA-256；Skill 选型读的就是这两份。

03

单文件里的放映体验

30 套共用同一套放映工具，不用另装播放器。

  • 画布与导航：1920×1080 自适应缩放；← / →、PageUp / PageDown、点击、滚轮或触屏手势翻页，输入页码按 Enter 跳页，也能在文件或网址后加 #3 直接定位。
  • 放映快捷键：F 全屏、S 演讲者视图（首次需允许本页弹窗）、O 总览、B / W 黑白屏、L 激光笔、D 画笔批注（C 清本页、Ctrl+Z 撤销，按页保留、刷新清空）、? 看全部快捷键。
  • 手机遥控：按 M 出二维码，但必须先用 python3 scripts/present.py 起本地服务；手机与电脑同 Wi-Fi，可翻页、看逐页讲稿、跳页、黑屏，也能用激光笔和画笔。配对码 6 位、服务停止即失效；直接双击或在线打开时 M 只显示说明。
  • 统一工具包：放映工具源码在 assets/toolkit.html，改完运行 python3 scripts/inject_toolkit.py 同步进各模板，并更新 catalog.json 里的校验值。14-live-model 的咖啡门店模板还能改假设、看联动计算。
样例数据要换掉：模板里的品牌、数字、研究来源和联系方式都是演示数据，按真实材料替换；终端模板显示的命令不会在网页里执行，实时模型的口径与业务结论也要自行校验。
04

安装为 Agent Skill

Python 3.10+ 即可，不装任何第三方 Python 依赖。

克隆 → 安装 → 新聊天里用示例提示

{{ texts.install }}
  • 装到哪：默认 ~/.codex/skills/lanshu-html-ppt-templates；设置了 CODEX_HOME 就用该目录下的 skills/。给其他支持 SKILL.md 的助手用 --skills-dir /path/to/your/skills 指定目录。
  • 安装器很克制：只复制 Skill 必需资源，并拒绝覆盖已有目录；装完要重开助手的新聊天，才能刷新技能发现。也可以不克隆，直接下载 GitHub Releases 的完整 ZIP（含原始模板与缩略图）。
  • 示例提示怎么写：点名 Skill → 说清页数与场景 → 指定风格 → 要求单文件 HTML 与逐页备注 → 粘贴材料。例如「做成 12 页产品发布演示，受众是企业客户，采用暗夜极光风格」。
  • Skill 会做什么：按内容与格式要求选模板 → 复制完整资源 → 改写页面和备注 → 执行静态检查 → 在可用浏览器中验证实际呈现。详细创作步骤见仓库 references/authoring.md。
直接改稿也完全够用：不装 Skill 也能去在线目录挑一套、下载 HTML 自己改。Skill 的价值是把「选哪套、页面怎么排、讲稿怎么写」这些判断交给 AI，适合批量出稿。
05

命令行工具 deck.py

查看、复制、检查，改稿前先把原模板复制出来。

列模板 / 建副本 / 读源码 / 校验 / 补字体 / 起遥控服务

{{ texts.cli }}
  • list / source：deck.py list 列出 30 套，list --pdf 只筛带多页打印样式的；deck.py source 07-consulting 输出精简源码，仅隐藏终端里的字体 Base64，原文件保持完整。
  • new：创建完整副本且不覆盖已有文件。--title 只改浏览器标题，封面、正文、品牌、图表和备注都要继续编辑；原始模板是一份可校验的副本，创作时先复制到自己的输出目录。
  • inspect / validate：检查页面结构、备注 JSON 与内联 JavaScript 语法（JS 校验需 Node.js）。静态检查不执行浏览器脚本，也证明不了版式、动画和 PDF 导出是否正确。
  • embed_fonts.py：改完文字后联网按页面实际用到的字重新裁剪内嵌字体；present.py 则提供局域网放映服务，配合浏览器里的 M 做手机遥控。
验证清单：内容改完人工检查首尾页、关键图表、最长正文、导航与备注；PDF 另做实际成品检查。这一步没法靠脚本替代。
06

在浏览器里直接改稿

按 E 进编辑，不用碰源码也能换文案。

  • 改文字与讲稿：点页面上带虚线框的文字直接修改；「文字与讲稿」面板里改本页讲稿和浏览器标题，用「全套替换」把样例里的公司名、产品名一次换掉（讲稿里的也一起换）。
  • 换主题色：「配色」面板用取色器实时预览，调完和文字一起保存在新文件里，原模板不动。
  • 另存为新文件：点「保存为新文件」或按 Ctrl+S，得到 原文件名（已编辑）.html；直接双击打开的本地文件，保存时需要再选一次原文件。
  • 字体边界：内嵌中文字体按原文字符裁剪，新写的字会先用系统字体显示，编辑面板会列出这些字；联网运行 python3 scripts/embed_fonts.py 文件.html 可重新裁剪。改稿后要检查字形、换行与溢出。
  • 脚本生成的文字改不了：终端打字、部分图表标签由 JS 生成，不能点选，要用「全套替换」；英文词出现在脚本生成内容里时，为避免改坏代码不会被替换，保存时会提示剩余处数。
建议顺序：先用「全套替换」和面板把内容、讲稿、配色改到位并另存，再按需打开 HTML 源码做精细调整；一上来直接改源码容易破坏内嵌字体和放映工具。
07

本地开发与部署

没有运行时 npm 依赖，也不需要 npm install。

校验 / 构建 / 预览 / 发版 / 部署

{{ texts.dev }}
  • 环境：模板创建与源码查看用 Python 3.10+，JavaScript 语法校验还需 Node.js，开发与部署建议 Node.js 22+。四个脚本分别做资源校验、生成 dist/ 站点与 release/ ZIP、本地预览、发布 Release 附件。
  • 部署：站点用 Cloudflare Workers Static Assets 托管模板，Custom Domains 绑定子域名，默认公开地址 ppt.lanshuagent.com；先 deploy.py --dry-run 预检，再 npm run deploy，工具固定 Wrangler 4.148.0。
  • 预览媒体不进版本库：高清视频与 30 段卡片预览按 preview-media.json 用 fetch_previews.py 校验下载，deploy.py 发布前会先执行这一步。构建目录只含公开站点资源，账号配置、缓存与 node_modules 都不进站点或 ZIP。
  • 完整包与校验：完整 Skill 与源码通过 GitHub Releases 分发，同目录 SHA256SUMS.txt 可核对；复用部署到自己的域名时，改 wrangler.jsonc 的 Worker 名与 routes[].pattern。
GitHub Actions：仓库自带校验工作流，推送与 PR 时会检查资源与构建结果。新增风格或改原始模板时，要同步更新 catalog.json、缩略图、选型目录与备注，再跑校验与构建。
08

适用判断、授权与限制

什么时候值得用，以及几条必须先知道的边界。

  • 适合谁：需要一份能离线放映、能直接发链接、带动画与交互的演示；想让 AI 助手按内容选风格并写好逐页讲稿；接受交付 HTML 而不是 .pptx。
  • 不适合谁：必须交可编辑 .pptx、对方要在 PowerPoint 里改；只想要一个静态主题、用不上放映工具与演讲者视图；或受众环境打不开 HTML。可编辑 .pptx 需要额外转换。
  • 授权要分开看（* 号说明）：新增 Skill、脚本、网站与文档按 MIT 开源；但原始模板、缩略图及内嵌字体保留各自权利，原始包未提供上游许可证，完整范围见 NOTICE.md。别把「项目 MIT」理解成「所有素材都能随便商用」。
  • 预览不等于主屏：演讲者视图用独立 iframe 显示当前页与下一页，默认不共享主屏临时调整的参数、随机种子和物件位置；总览缩略图与手机预览也是独立实例。
  • 版本信息有点错位：GitHub 仓库描述仍写「20 套 / 226 页」，README 与 catalog.json 已更新到 30 套 / 338 页 —— 以后者为准。仓库 2026-11-04 创建、64 star，还很新。
建议姿势：先去在线目录挑一套（比如 07-consulting 或 03-aurora）下载双击，把快捷键与演讲者视图过一遍；再把整套装成 Skill，用示例提示让 AI 出一版 12 页演示；最后按 E 在浏览器里改文案与讲稿。别一上来就改模板源码。
