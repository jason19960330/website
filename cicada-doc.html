01

它到底是什么

一个听得懂、说得出、记得住的跨平台会议助手——不是录音笔，而是实时双语字幕 + 同声传译 + AI 纪要三件套。

  • 定位是「实时会议/直播的字幕与同传工具」：无论是 Zoom、飞书、腾讯会议开会，还是听 X Spaces、YouTube 直播，它都直接读取系统播放的声音，把对方说的话实时翻成你的语言。
  • 不往会里塞机器人：它读的是你 Mac/PC 的系统音频，对方完全无感——不会出现「某某已加入会议」的提示，也不需要对方装任何东西。
  • Mac 端本机优先：在 macOS 上，声音采集、语言识别、语音识别、会议录音全部在本机完成，声音不出电脑；只有识别出的文字才会上网做翻译和纪要。
  • 四端通用：Mac、Windows、Linux、Android 共用一个版本号与同一套会议记录格式，安装包在官网与 Releases 同步发布。作者 @wquguru 以 Apache-2.0 开源。
形态：一个桌面/移动 App（Swift + SwiftUI 为主）。Mac 版零第三方依赖，从源码构建只需 Xcode 命令行工具；它不是库、不是网页服务，而是装好即用的应用。
02

核心功能一览

五件事一次到位：边听边写纪要、实时字幕、线下会议、同声传译、可回看的会议记录。

  • 实时纪要与双语文字记录：开会时纪要窗口边听边整理总结、议题/结论/待办/鱼骨图/人名术语表；点结论或待办可跳回双语记录里的原话；统一人名术语写法并记录听错变体。
  • 实时字幕与语言识别：对方开口几秒自动识别语言并翻成系统语言；字幕条只在有人说话时出现，鼠标划过自动变透明，不挡按钮。
  • 线下/会议室模式：把「听哪里」改成「会议室」就用麦克风听桌边的人；macOS 26 还支持「电脑 + 会议室」双源，用回声消除去重。
  • 同声传译：按住 Mac 右 ⌥ 说话，对方在会议软件里直接听到翻译后的语音（经一键装的虚拟麦克风）；可声纹克隆自己的声音。
  • 会议记录与导出：每场会议的双语文字、纪要、原始录音存本机；识别说话人并改名合并；导出 Markdown / Word / SRT，也能导入已有录音视频转写。
小提示：「实时纪要」和「一步语音翻译」需要你自己的 Ling（蚂蚁集团大模型）key；这两项不填 key 用不了，但字幕、翻译、会议记录、同传（系统语音）都照常工作。
03

四大平台与系统要求

同一份代码四端通用，但能力有梯度：Mac 功能最全且本机识别，其余三端需填 AI key。

  • Mac（功能最全）：macOS 14.4+，Apple 芯片。声音采集、语言识别、语音识别、录音全在本机；不填 key 也能用字幕/翻译/记录/同传（系统语音）。
  • Windows：Windows 10 2004+，x64 / ARM64。需要 Ling key（用不了时可换 OpenRouter、ZenMux 等）；同传装免费 VB-Cable 虚拟麦克风。
  • Linux：Ubuntu 22.04 / 24.04 桌面版（x86_64 / arm64）。需要 Ling 或其他 AI key；同传自建「知了 麦克风」，无需装驱动；纪要窗会被屏幕共享看到。
  • Android：Android 10+。需要 Ling 或其他 AI key；视频/直播字幕、面对面互译；微信等通话声音系统不让录，需开外放改选「面对面」。
为什么有差异：只有 Apple 平台提供本机语音识别与翻译框架，所以 Mac 能离线跑核心链路；Win/Linux/Android 没有等价本机能力，声音需分段发给云端识别，因此必须填一个 AI 服务 key。

  • 下载安装（最省事）：去 Releases 或官网下 Cicada-<版本>-macOS-AppleSilicon.dmg，打开拖进应用程序。目前本地签名未公证，首次打开被拦时去「隐私与安全性」点仍要打开；安装包附 checksums.txt 可核对 SHA-256。
  • 配置 Ling key：到 Ling 开放平台注册 → 创建令牌复制 sk- 开头的 key → 在知了「设置 › AI 服务」粘贴保存。约 0.15–1 元/小时，Ling 每月赠 10 元额度（约 10–50 小时会议）。
  • 换个服务也行：在「设置 › AI 服务」右上角可换成 OpenRouter、ZenMux、OpenAI，或任意 OpenAI 兼容地址（含本机模型）。实时纪要和整句翻译都能用；一步语音翻译与声音克隆仅 Ling 有。
05

实时字幕与双语记录

不填 key 也能用的核心能力：自动识别对方语言、实时翻成你的语言、并记下可搜索的双语原文。

  • 自动语言识别：对方开口几秒即在本地认出语言并翻成系统语言；按 ⌃⌥S 可在「纪要窗口 / 字幕条 / 不显示」间切换。
  • 不挡操作的字幕条：字幕条只在有人说话时出现，鼠标划过自动变透明，不会挡住底下的会议按钮。
  • 双语文字记录：完整保留原文与译文；纪要窗口边听边写总结、议题、结论、待办、鱼骨图、人名术语表。
  • 统一人名术语：自动统一文中人名与术语写法并记录听错变体，⌘F 搜索时能连同识别错的写法一起搜出来。
无 key 也能用：Mac 上实时字幕、翻译（Google → macOS 26 本机）、会议记录、同传（Mac 自带语音）都不依赖 Ling key；只有实时纪要、一步语音翻译、声音克隆需要它。
06

同声传译与会议纪要

开口即译、按住即说；会议结束还能回看、改名、导出，或把旧录音视频拖进来转写。

  • 一键同传：按住 Mac 右 ⌥（Windows 右 Ctrl）说话，对方在会议软件里直接听到翻译语音；开启时自动把系统麦克风切到一键安装的虚拟驱动 BlackHole 2ch。
  • 声音克隆：填了 Ling key 后可用自然人声，或用 8–30 秒录音克隆你自己的声音；不填也能用 Mac 自带语音。
  • 说话人识别：按声音区分不同说话人，有 key 时填名字；认错了在实时纪要窗口里就能改名、合并或把某段改给别人。
  • 会后处理：挂断或 10 分钟无人说话自动结束并截空白；随时可补生成纪要，或导出 Markdown / Word / SRT；已有录音视频拖进窗口即可本机快速转成双语记录。
边界提醒：目前记录里的「你」只包含按住说话键说的话，会上直接开口的部分尚未纳入——作者已把它列进路线图（「记录我的发言」），届时持续听麦克风并做回声消除。
07

隐私与本机模型

默认离线、无遥测、无自建服务器；离开电脑的只有识别出的文字，且只在你需要时。

  • Mac 本机优先：声音采集、语言识别（Apple SpeechAnalyzer / SFSpeechRecognizer）、语音识别、会议录音全部在本机；只有识别出的文字会上网做翻译与纪要。
  • 无统计、无自有服务器：应用没有埋点，也没有作者自己的服务器；诊断只把耗时和次数记在本机会议文件夹里。屏幕共享/录屏拍不到纪要窗口。
  • 模型分工：语音/语言识别走 Apple 本机；整句翻译默认 Ling Ling-3.1-flash（退回 Google → macOS 26 本机）；同传听懂你说用 Ming Ming-3.0-audio-flash、声音用 Ming-3.0-tts-0.5B；说话人识别用随附的 WeSpeaker 声纹（本机 Core ML）。
  • 安全边界：网络图像需授权、仅 https 公共主机、单张 ≤10MB；不可信图像在沙盒辅助进程解码；Ling key 与声音样本仅当前账户可读，不进备份与日志。

08

适用场景与边界

什么时候该装、什么时候有门槛，以及作者正在补的能力。

  • 适合：跨语言会议/直播：和外籍同事开会、听海外直播/播客/X Spaces，实时双语字幕 + 纪要大幅降低语言门槛。
  • 适合：需要同传的发言场景：跨国电话会里你想用中文说、对方听译文，按住说话键即可，无需对方装任何插件。
  • 适合：会后归档：导出 Markdown/Word/SRT 进笔记或知识库；旧录音/视频也能拖进来转成双语记录。
  • 前提门槛：实时纪要、一步语音翻译、声音克隆需要 Ling（或兼容）key；非 Mac 端连字幕也需填 key。
  • 路线图：记录我直接开口发言、正式签名与 key 进系统钥匙串、本机声纹记忆、无 key 也有纪要、Android 上架商店、iPhone/iPad 支持。
