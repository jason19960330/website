01

它到底是什么

不是图表库，而是一套「教 Agent 怎么把图画得有编辑品味」的规则 + 现成模板。 装上之后，Agent 出图时会被规则约束，不能随意自由发挥。

  • 模板驱动：每张图必须先锁定图型编号，再复制仓库里该图型的真实实现骨架，禁止另画一张「看起来差不多」的图，也禁止退回图表库默认样式。
  • 先判形状，再选图：比较、时间序列、占比、带正负、分布、网络、逐条记录——数据形状才是选图的主键，不用你指定图型。
  • 统一视觉语法：统一的字体、留白、发丝线与动效节奏，默认 Mono 黑白灰，也可切换青瓷蓝 / 椰林绿 / 编辑部红三套彩色。
  • 图数由结论数决定：一个问题出 1 张，2–3 个结论出 2–3 张，长文 4–6 张，单页上限 6 张，不会为了凑数硬加图。
为什么它出的图比普通 AI 好看：因为 Agent 不是在「凭空生成 SVG」， 而是在一套已经调好比例、留白和动效的真实模板上替换数据。

03

场景一 · 给文章制作数据配图

最适合数据型、研究型、工具测评型长文。出图自带排版和旁注，普通内容直接用完全够， 能明显提升文章的专业感。

X 长文 / 公众号配图 4–6 张小红书数据配图 短帖的一张关键结论图 深度报告拆成可传播的数据结论 多工具多维度测评对比
  • 不需要提前想好用柱状图、折线图还是散点图——把数据和使用场景告诉它，它先判断数据结构再选模板。
  • 一次让它在同一批里出多张图时，它会避免重复图型，每张图只承担一个独立结论。
  • 数据里有真实单位就保留真实单位；取整造成的误差会在底注里「认账」，不会偷偷凑成整数。

配图数量按「结论数」来，不是按数据列数来：一篇文章 4–6 张就够， 再多就该拆成多页。

场景二 · 给视频制作动态数据画面

部分模板自带滚动入场、数字递增、动态排名和交互效果。 生成 HTML 后用浏览器录屏，就是现成的视频素材。

视频开场 口播中的数据证据 排名变化动画 趋势演示 B-roll 数据素材
  • G16 Bar Race、G18 Draw-in + Counter、G12 Stagger Wave 这几个模板本身就是为动效设计的。
  • 录屏前把浏览器窗口调到目标比例（如 1080×1920 竖屏），全屏后再录，避免缩放糊边。
  • 如果本机开了「减少动态效果」，动画会被系统降级——录屏前记得关掉。

场景三 · 生成完整的数据报告

只有当你明确说出「报告 / 白皮书 / 海报 / brief / Dashboard 报告」这类词时， 它才会切换到报告模式，从 12 套中英文整页模板里选一套。

调研一页纸 年度数据海报 月度运营报告 研究简报 产品与项目复盘 数据 Dashboard 个人年度记录
  • 报告不是把几张图堆在一起，而是同时组织标题、核心结论、KPI、图表、旁注、数据来源和结尾。
  • 每套模板都有中文版和英文版，同一份报告里不混语言；版心从 600 到 1080px 不等，密度分低 / 中 / 高。
  • 金融经济、业务运营、产品复盘、个人年度记录都能套用——不要被模板名字里的行业词限制住。

统一成自己的品牌色

Skill 自带的美商已经够用；如果你有品牌视觉，也可以让它整批换成你的主题色。

  • 有完整色值就直接给色值；让它建立一套 custom 色板，同一批图只用这一套。
  • 没有完整色值也没关系：给一张参考图，让它只提取颜色逻辑，不复制原图构图。
  • 换色后仍要保持图型结构、比例、对比度和数据含义不变——颜色只换肤，不改数据契约。

07

三条硬规则（写指令时记住就够）

  • 给数据 + 给场景，不给图型。你说要柱状图，反而可能限制它选出更诚实的编码方式。
  • 单一色系。同一份 HTML 或同一组图只使用一种色彩系统，不混搭。
  • 不要让它编数据。没有的数据就空着；模板里带演示数据的槽位要主动删掉。

使用须知

  • 许可是 PolyForm Noncommercial 1.0：学习、修改、非商业使用都可以，商业用途需要另行取得作者授权。
  • 部分图表依赖 CDN：Glance 系列、网络图 / 力导向图，以及报告模板 R11、R12 需要联网加载 ECharts / Chart.js；要离线用就选 R01–R10 并把字体内联。
  • 仓库体积约 27MB（主要是模板与预览图），SKILL.md 本身 37KB，建议只在需要出图时才启用这个 Skill。
  • 地图要显式要求：默认不会给你地图图型，需要地域分布时明确说出来。
