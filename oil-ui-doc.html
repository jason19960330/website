01

它到底是什么

一句话：把 AI 编程 Agent 的 UI 与交互设计能力推向高审美的外挂脑。

  • 定位：Oil UI 是开源的界面与 UI/UX 设计 Skill，仓库 oil-oil/oil-ui，官网 ui.oiloil.org，MIT 开源。专供 Claude Code、Cursor、Windsurf、Codex、Antigravity 等编程 Agent 载入。
  • 解决的痛点：大部分 AI 生成的网页都有一种典型的「AI 塑料味」——千篇一律的紫色发光渐变、无意义的圆角胶囊眉标、左侧粗彩条、三层嵌套卡片以及虚假数据指标。Oil UI 专门约束模型打破这种惯性。
  • 两种工作模式：默认模式下，Agent 会根据业务属性推荐一个最明确、最适宜的视觉方向，并对照浏览器真实截图精修；对比模式下，Agent 会并排输出 3 套差异巨大的构图方案供你抉择。
  • 全品类覆盖：不是只做单一落地页，作品集、SaaS 营销官网、复杂后台控制台、移动端 Web App、单组件精修以及轻量 H5 游戏演出手感均有针对性规范。
体量与战绩：GitHub 收藏 3.8k+，线上展示 143 件真实作品。在 15 次匿名视觉盲测中均分达到 87.0/100，大幅领先无 Skill 对照组与通用 UI 提示词组。
02

3 方向探索与视觉定调

真正拉开差距，绝不是换个主色调的“假对比”。

  • 认品类与定调性：拿到产品需求后，首先分析业务所属品类（如战略咨询、极简工具、潮流社区、重工业制造），匹配该行业具有记忆点的情感基调与排版语境。
  • 三维度拉开差距：当要求探索多方向时，Oil UI 要求 Agent 必须在「页面构图（Layout Structure）」、「字体排印（Typography）」与「配色体系（Palette）」三处同时形成鲜明对照。
  • 经典范例拆解：例如对同一个特展页面，方案 A 采用「极简杂志网格 + 细无衬线体」，方案 B 采用「古典报刊排版 + 衬线体大标题」，方案 C 采用「暗调漫反射 + 错落流动布局」，给你真正的审美选型空间。
  • 一键定案推进：选定满意方向后，生成一句包含选中方案 ID 与排版参数的标准 Prompt，交由 Agent 顺畅进入下阶段的完整功能编码。
为什么不自己盲目想：人类直觉容易陷入既有经验，AI 盲目生成又容易滑向套路模板；3 方向并排呈现能让人迅速在直观对比中找到最契合业务直觉的形态。
03

风格对比页与真实打磨

自带轻量容器，在真实浏览器视口里做像素级验收。

  • 内置 Proof 页面容器：自动将生成的多种方案组合在一个单文件对比页面中。支持放入静态 HTML、高清截图甚至本地开发服务热更新的实时 iframe。
  • 多端视口无缝切换：对比页自带一键切换「桌面宽屏（Desktop）」与「移动端手机（Mobile）」尺寸，快速验证流式响应式表现。
  • 快捷键高效翻看：支持键盘左右方向键 ← → 翻页巡检，空格放大查看实际像素大小，不依赖任何重型设计软件。
  • 对照真实截图打磨：借助 AI 视觉能力抓取实际渲染的页面截图进行比对，定位错位断行、对比度不足或视觉重心偏移，实施像素级复核。
真渲染原则：代码写得再优雅，最终用户的评判标准依然是浏览器渲染出的视觉。Proof 容器让比选和评审全部发生在真实的 DOM 环境里。
04

安装与兼容宿主

一行命令即装即用，支持全主流 AI 编程环境。

  • 极简安装：直接在项目根目录运行 npx skills add oil-oil/oil-ui 即可全自动注入当前宿主的 Skill 体系。
  • 宿主全兼容：全面适配 Claude Code、Cursor、Windsurf、Codex、Cline、Antigravity（Google AGY）、OpenCode、GitHub Copilot、Roo Code、Trae 等支持 SKILL.md 体系的 Agent。
  • DeepSeek 原生接入：针对 DeepSeek Harness 提供 dsh-oil-ui 官方插件，一行命令加载并自动识别本地配置。

05

常用提示词与交互实战

贴近开发流程，覆盖从探索、翻新到规范沉淀四类典型场景。

  • 新页面风格探索：向 Agent 描述业务主题与期望受众，要求生成 3 个对比方案并拉开构图差距。
  • 老项目无损翻新：遵循「清噪音、调布局、省步骤」三步法，既大幅提升颜值，又不改动现有前后端数据交互与表单校验。
  • 专项去塑料感走查：针对已有原型执行严格减法，去除生造的假数据与冗余渐变元素。
  • 沉淀全站设计规范：在确认首个页面的基调后，指示 Agent 将色彩系统、字阶比例与组件规范沉淀为全站统一的 DESIGN.md。

06

反 AI 塑料感与评审标准

清晰的减法规则，把生硬的生成物改造成像专业设计师的手笔。

  • 去除廉价光效：杜绝为了所谓“现代感”而滥用的全局紫色/粉色霓虹模糊投影与外发光。
  • 拍平无序容器：打破卡片套卡片的思维定式，多采用整齐有节奏的分割线与纯留白组织信息。
  • 克制而笃定的字阶：建立清晰的排版阶梯，主标、副标、正文、辅助说明的字重与色彩对比层次分明。
  • 真实内容优先：坚决摒弃虚构的无意义指标百分比，突出真实产品特性、代码样例或数据截图。

07

开源版与 Pro 差异

开源版做好单页设计，Pro 版负责全流程质量兜底与艺术级落地。

  • 开源免费版已非常强大：支持完整的认品类、定调性、3 方向并排拉开、风格对比页、基础视觉评审与截图还原，足以高质量从零搞定单个漂亮页面。
  • Pro 进阶能力：增加默认盲审 + 深度打磨（冲 9 分 UX 复核）、全站一页铺一套跨页一致性检查、老项目安全改造流程、19 套卡片原型与复杂动效组件。
  • 免费附赠 Oil Art Landing：Pro 附带艺术官网独立 Skill，收录桌面与移动 App 丰富视觉锚点（极地冰川、暗房胶片、玄武岩石、长虹玻璃等），支持前景遮挡与视差落地。

08

适用判断、生态搭配与边界

明确能力边界，与周边动效与文案工具形成协同效应。

  • 最佳适用场景：SaaS 官网与落地页、个人作品集、技术工具主页、管理后台/控制台工作区、移动端 H5 界面重构。
  • 不适用的场景：纯后端业务逻辑实现、复杂的数据库表结构设计、单纯的基础算法优化（这些交由通用编程 Agent 即可）。
  • 官方生态搭配：配合 oil-motion 实现随滚动/拖拽触发的高级微动效；配合 oil-tone 润色全站文案，确保中英文语调自然清晰。
  • 隐私与轻量检查：Skill 仅在本地执行，不上传任何私有业务代码；最多每 10 分钟单次联网读取官方版本列表，可用 OIL_NO_UPDATE_CHECK=1 完全关闭。
