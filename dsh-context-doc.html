dsh-context 完整指南

一款给 AI Agent 装的「上下文透视镜」——DeepSeek Harness 插件：把 Agent 此刻携带的上下文（系统提示词、工具定义、历史消息、模型思考、工具结果）可视化， 看清它怎么构成、怎么随对话膨胀与压缩、多 Agent 协作时各自占了多大窗口。下面把 8 个主题的完整内容整理在一页里，从上往下读即可。

01

它到底是什么

不是独立网站或 App，而是给 DeepSeek Harness 装的一个插件：把 Agent 正在携带的上下文全生命周期管理起来。

  • 它解决的是「看不见」的问题：对话越长，上下文窗口越满，但到底被什么占满了、哪一步开始退化，肉眼完全看不出来——dsh-context 把这一切摊开给你看。
  • 同一个故事的五种讲法：上下文洞察页、Context 标签页、Fleet 标签页、侧边栏面板、/context 命令，入口不同，看的是同一份上下文数据。
  • 被官方推荐：获 DeepSeek Harness 团队成员 [@tianyicui]、[@turtle1999] 推荐并加星，定位是「适用于 Agent 上下文洞察与管理的最佳 Harness 插件」。
  • 装完即用：cordis 插件，TypeScript 编写，Apache-2.0 许可；无需构建、无需重启，装完即可在侧边栏和会话里看到。
形态：DeepSeek Harness 插件（cordis-plugin）。运行在 Harness 内部，读它自己的会话日志（V4 格式），因此不依赖第三方服务，也不会把你的对话发到别处。
02

快速开始

两种方式都能装，都不需要碰构建工具。装完用 dsh web 启动 Web UI 即可。

在 DeepSeek Harness 里安装（推荐）

{{ texts.install }}
  • 图形界面装：在 Add plugin 向导的搜索框里填 dsh-context，点 Install 即可（网页版 / 桌面版通用）。
  • 命令行装：dsh plugin --profile web add dsh-context，随后 dsh web 启动界面。
  • 升级：dsh plugin --profile web update dsh-context@latest，再 dsh web 即可，不用重装。
  • 兼容性：要求 @deepseek-ai/dsh 0.2.0-rc.2 及以上（0.2.0 / 0.2.1 系列已验证）；UI 内置英文与简体中文。

03

五大功能入口

五个入口看的是同一份上下文数据，区别只是「在什么场景下、以什么形态」呈现给你。

  • ① 上下文洞察页面（一级侧边栏）：跨会话总览，与 Plugins、Automation tasks 并列。含 7 天 Token/成本 KPI 栏、7 天使用量成对柱状图、活动热力图、组成环形图，以及可按时间/搜索筛选、一键跳转任一会话的会话卡片。
  • ② Context 标签页：打开任意会话后，完整的上下文仪表板——统计、组成、逐请求趋势、事件、文件活动、命令执行。
  • ③ Fleet 标签页：Agent 家族专属页，当前 Agent、它的父级、所有子 Agent 各显示一张实时卡片。
  • ④ Context 面板（右侧边栏）：把同一个仪表板钉在聊天旁边，侧边栏选 Context 即开，含 Agent 网络。
  • ⑤ /context 命令：在输入框敲 /context，居中弹窗显示当前上下文组成与浏览器，不离开聊天。
偏好设置里可单独开关「Context 面板入口」（会话标签页 / 右侧栏 / 两者 / 隐藏）与「Fleet 标签页」显示，详见第 07 篇。
04

上下文仪表板

Context 标签页里一组互相联动的卡片，从「总量」到「逐请求演变」逐层下钻。

  • Context Stats：轮次、步骤、用户输入、实时工具调用，以及按 models.dev 价格估算的成本（悬停 ? 看单价；DeepSeek 高峰时段按 2 倍计）。
  • Token Stats：计费 Token 总量按组成拆分——系统提示词、工具定义、消息、模型思考……环形末端是会话缓存命中率。
  • Timing Stats：活跃时间在「模型调用 / 工具运行 / 开销」之间的分布。
  • Current Context：此刻窗口里的内容，六色堆叠条（系统提示词 / 工具定义 / 用户消息 / 注入上下文 / 助手回复 / 工具结果），每条显示约略 Token 与占比——对话开始退化时，能在这里看到具体是哪块撑爆了窗口。
  • Context Trend：每个模型请求一根堆叠柱，比按消息更细，可逐轮看窗口增长；支持 Step/Turn、Total/Delta，压缩事件直接标在柱上。
  • Context Events：注入 / 压缩 / 清理 / 模型切换 / 模式切换都记录下来，标注来源与 Token 净变化。
  • File Activity：Agent 对你的文件做了什么——读取 / 写入 / 搜索，含行数增减估算。
  • 命令执行：Agent 跑了哪些 Shell / 代码，状态、耗时、程序分布一目了然。
标题里的占用率与组成，读的是和聊天框上下文环形图相同的官方 Token 计量投影（contextPressure / contextBreakdown），所以数值始终与环形图一致，精确到小数点后一位。
05

上下文浏览器

想知道「某一次请求到底是哪些内容拼出来的」？选 Live 或任一保留步骤，逐类展开看真实内容。

  • 七类可折叠：系统提示词、工具定义、消息、推理、工具参数、工具输出、技能注入（Skill Injections 单独成类，隐蔽技能不藏进「注入上下文」或「工具结果」）。每项显示 Token 开销，可再展开看实际内容。
  • 工具来源标签：每个工具定义带来源识别——tool-* 一方包、dsh-* 功能包、mcp:<server> 代理，或 tools.register() 实时监控到的确切插件；可按大小/名称排序、可搜索。
  • 助手回复按类型筛：搜索框含 Thinking / Tools / Answer 标签，点一下只留匹配的回复类型。
  • 工具结果展开看完整调用：工具名、参数与 OK/error 状态，结果正文支持 Raw / Markdown 切换。
  • 附件卡片：消息里的 image / file 区块按序成卡，图片显示缩略图、尺寸、存储大小与官方图像 Token 估算；点击在预览栏打开（支持 Markdown / 代码 / PDF / Office / 图片）。
  • 与上一轮对比：各类别的有符号差异徽标（+N 项、±Nk Token）让你一眼看出某轮新增或回收了什么。
  • DNA 模式：把上下文按模型读取顺序平铺成色带与列表（最新在上），每行带在提示词中的位置 #12、类别、引入步骤、Token 开销。
06

Fleet 编队与通讯

多 Agent 协作时，整支队伍拥有自己的页面，把「谁在做什么、跟谁说了什么」一次看全。

  • Agent Network：当前 Agent、它的父级、所有子 Agent 各一张卡，显示实时上下文大小、窗口占用率、组成条、运行时长与已执行步数；血缘连线按关系着色，运行中 Agent 有绿色脉冲指示。
  • 编队成员与任务：每张成员卡显示角色（主控/队友）、运行模型、最新回复、时长、步数、进行中任务数；下方任务板按负责人分组、可按状态筛选，聚焦某任务时整条阻塞前置链一起点亮。
  • 通讯记录：自动读编队会话日志，把团队私信、邮箱投递、运行时结算通知合并成通道——每张通道卡配对双方身份与消息数，时间线标角色；点开任一条内联展开完整记录与参与者卡片。
右侧 Sidebar 的 Context 面板会内嵌同一套 Fleet 卡片；若用不到，可在偏好设置里关闭「Fleet tab」（卡片仍保留在面板中）。
07

设置与偏好

用户级设置都在 Plugins 页里 dsh-context 的 Configuration 卡片，改完即时生效。

  • Context 面板入口：会话标签页 / 右侧 Sidebar / 两者 / 隐藏——隐藏后回复行的跳转按钮也一并隐藏。
  • Fleet 标签页开关：独立于上面的面板入口，单独控制是否显示 Fleet 标签页。
  • 洞察默认时间范围：今天 / 近 7 天 / 近 30 天（默认）/ 全部；在页面上点时间预设会写回此项。
  • 图表与排序默认值：趋势粒度（Step/Turn）、趋势模式（Total/Delta）、默认时长曲线、自动总览阈值、浏览器对比基线、工具与文件活动排序，都可预设。
  • System Prompt 前缀 / 后缀：自由文本，拼接到每个会话系统提示词的最前 / 最后，对所有 Agent（含子 Agent）生效——相当于随 Harness 自身组装流程应用的部署级角色设定或行为规则，下一轮起生效，留空即停用。
08

适用场景与边界

它不改变 Agent 的行为，只让你「看得见」——下面说清什么时候最有用、以及数字该怎么读。

  • 上下文快撑爆却找不到原因：Current Context 六色条直接指出是哪块（系统提示词？工具定义？历史消息？）在膨胀。
  • 多 Agent 协作想看各自占用：Fleet 的 Agent Network 把父 / 子 Agent 的上下文与成本并排。
  • 想优化提示词 / 工具定义体积：Token Stats 与上下文浏览器能精确定位「最贵」的那段内容。
  • 想复盘 Agent 到底做了什么：File Activity 与命令执行记录每一步读写了哪些文件、跑了哪些命令。
  • 估算值 vs 实际值：各类别采用 dsh 固定密度启发式（与内置 Token 计量器同源）；固定趋势明细会在一旁显示服务商报告的实际值，Token 卡片则把估算占比与精确计费总量并列呈现。
  • 兼容性边界：仅支持 V4 会话日志格式的 @deepseek-ai/dsh 0.2.0-rc.2 及以上；更早版本不保证可解析。
